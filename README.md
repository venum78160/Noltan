# Statistiques de téléchargement

Relevé quotidien des compteurs de téléchargement des releases (API GitHub),
une ligne par fichier et par jour : date, tag, fichier, cumul.
Le cumul additionne nouveaux téléchargements et mises à jour automatiques
des postes déjà installés : c'est un plafond, pas un nombre d'essais.
